# Prime Connect - نظام الموظفين والوظائف

نظام ويب فيه تسجيل دخول، وحساب رئيسي واحد (المالك) هو اللي بيحدد صلاحيات كل الحسابات التانية.

- **الحساب الرئيسي (Owner)**: أول حساب بيتعمل عند تشغيل السيستم لأول مرة (عن طريق ADMIN_USERNAME / ADMIN_PASSWORD). عنده كل الصلاحيات دايمًا ومينفعش حد يعدلها أو يحذفها.
- **أي حساب موظف تاني**: يبدأ بصلاحيات افتراضية بسيطة (بحث وإضافة مرشحين، تسجيل توظيفات)، والمالك يقدر من تاب "الحسابات والصلاحيات" يفعّل أو يلغي أي صلاحية لأي حساب في أي وقت: إدارة الوظائف، عرض/إضافة/تعديل المرشحين، عرض/إدارة العملاء، عرض/إضافة/تعديل التوظيفات، أو حتى صلاحية إدارة الحسابات نفسها.

## تشغيل السيستم على جهازك (اختياري، للتجربة فقط)
```
npm install
ADMIN_USERNAME=admin ADMIN_PASSWORD=YourStrongPassword npm start
```
هيشتغل على http://localhost:3000

## رفعه على الإنترنت بدومين خاص بيك (الخطوات الفعلية)

أسهل طريقة هي **Render.com** (فيه باقة مجانية، وبيدعم ربط دومين خاص):

1. اعمل حساب على https://render.com وسجّل دخول بحساب GitHub.
2. ارفع فولدر المشروع ده على GitHub (repository جديد).
3. من Render، اختر "New Web Service" واربطه بالـ repo.
4. في الإعدادات:
   - Build Command: `npm install`
   - Start Command: `npm start`
5. في قسم Environment Variables ضيف:
   - `ADMIN_USERNAME` = اسم المستخدم اللي هتدخل بيه كمدير
   - `ADMIN_PASSWORD` = كلمة مرور قوية (غيّرها عن القيمة الافتراضية)
   - `SESSION_SECRET` = أي نص عشوائي طويل (لأمان الجلسات)
6. بعد أول تشغيل، السيستم هيديك رابط زي `prime-connect.onrender.com`.
7. لو عايز دومين خاص بيك (زي `system.primeconnect.com`):
   - اشتري الدومين من أي مسجّل (Namecheap, GoDaddy, إلخ).
   - من إعدادات Render، اختر "Custom Domain" وضيف الدومين، وهيديك سجل DNS تضيفه عند مسجّل الدومين.

> ملحوظة: البيانات بتتخزن في ملف `data.json` جوه السيرفر. لو حجم البيانات كبر مع الوقت، يفضل الانتقال لقاعدة بيانات حقيقية (Postgres مثلاً) — قولّي لو وصلتوا للمرحلة دي وهساعدك.

## أول حاجة تعملها بعد الرفع
سجّل دخول بحساب المالك، روح تاب "الحسابات والصلاحيات"، واعمل حساب لكل موظف وحدد بالظبط الصلاحيات اللي يحتاجها (تقدر تعدلها في أي وقت بعد كده).
